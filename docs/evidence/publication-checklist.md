# Public portfolio — evidence and fact-check checklist

## Identity and contact
- [ ] Confirm preferred professional title.
- [ ] Add approved professional portrait (optional).
- [ ] Confirm public email address.
- [ ] Confirm current location wording.
- [ ] Verify GitHub and LinkedIn profile URLs.

## Education and career
- [ ] Exact degree title and specialization.
- [ ] Institution and dates.
- [ ] Employment / consulting roles, organizations and dates.
- [ ] Responsibilities and measurable outcomes.
- [ ] Certifications with issuer and date.
- [ ] Languages and proficiency levels.

## Projects
- [ ] Confirm current project status.
- [ ] Confirm role and ownership / contribution.
- [ ] Separate implemented features from roadmap.
- [ ] Confirm live URLs.
- [ ] Add screenshots with anonymized data.
- [ ] Add architecture diagrams and test evidence.
- [ ] Verify quantitative metrics from source records.
- [ ] Obtain permission for client / partner references.

## International collaboration
- [ ] Do not identify 3Wheels.ai as a client or partner unless an agreement is concluded and disclosure is authorized.
- [ ] Do not publish the NDA, private repository links, negotiation details or evaluation material.
- [ ] Describe only general capabilities in private repository management and software delivery.

## UNICEF / MenstruAI
- [ ] Verify the application submission status.
- [ ] Do not claim selection, funding or endorsement without official confirmation.
- [ ] Do not imply ABPF / UNFPA partnership without written confirmation.
- [ ] Review health content, privacy, safeguarding and AI limitations with qualified experts.

## Security
- [ ] Scan repository for secrets before making it public.
- [ ] Remove private URLs, credentials, personal data and client data.
- [ ] Review all screenshots and documents.
- [ ] Check third-party asset licenses.
